## This Presentation vs. The Previous One

The combined "Governed Agent" presentation told the *philosophical* story — AI evolution, the crisis, the abstraction. This presentation tells the *operational* story: here is the actual process, the actual stages, the actual artifacts, the actual tools. **Different visual world accordingly.**

## The Visual World: The Forge

Where the previous presentation used the *Governance Void* (infinite abstract space, particles finding order), this presentation uses **The Forge** — a dark, precision industrial workshop where every stage of the SDLC is a distinct workstation, and a tangible artifact is produced at each one.

The metaphor is deliberate: a forge takes raw material and produces something precise and strong through structured heat, pressure, and craft. Each stage of the SDLC is a forging station. The final sprint summary is the sealed product — bound, stamped, permanent.

**The shop floor is always the same dark space.** The workstation in each slide is different, but the ambiance (dark steel, precision lighting, warm forge-glow in the background) ties all 17 videos together as one environment.

## Loop Mechanism Reference

| Code | Mechanism | Best for |
|------|-----------|---------|
| **LM1** | Inherently periodic motion | Pendulum, flame flicker, gauge needles, pulse cycles |
| **LM2** | Crossfade blend loop | Continuous data flow, smoke, particle drift |
| **LM3** | Boomerang (forward + reverse) | Assembly/disassembly, writing/sealing, construction steps |
| **LM4** | Start=End anchor (Veo2 hint + LM2 backup) | Slow breathing scenes |

**Rule:** Video = atmosphere and metaphor. GSAP overlay = all text, numbers, stage labels, tool names, artifact names. Veo2 generates NO readable text.

**Left page — What was specified and documented:**
- Spec entries: glowing blue file-shaped icons (specs/)
- Doc entries: teal document icons (docs/)

**Right page — What was built and verified:**
- File change indicators: orange forge-colored file icons (files changed/created)

- Coverage arc: a circular progress arc in emerald, nearly full

Then: the book slowly OPENS again, beginning the next cycle.

**Motion:**  
- Entries fill the pages in sequence (LM3 boomerang — fill in, hold at complete, pages blank, fill again)
- Book close: mid-cycle (LM3 — the ceremonial close is the peak of the cycle)
- Emerald seal light: LM1 pulse along spine when closed
- Book reopen: returning to the blank state for the loop start

**Loop:** LM3 fill → close → seal → open → blank → fill. **15s** (this is the most important slide; give it time).

**Palette:**

**Why this slide matters — speaker note:**
