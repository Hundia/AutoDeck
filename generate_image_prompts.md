# The Governed Agent — Start-Frame Image Generation Prompts
### 20 prompts · Copy-paste ready for Google Stitch / Imagen 3
### Each image = the first frame of a looping background video (Veo2 image-to-video next step)

---

## How to Use

1. Generate each prompt at **16:9 aspect ratio** (1920×1080 or higher).
2. Generate **2–4 variations** per slide; pick the one with the cleanest "text-safe zone" (the area described per slide must stay dark and low-detail).
3. The images should feel **dark** — darker than instinct says. If it looks "right" in the generator, it's probably too bright. The CSS scrim and overlay text need ≤20% luminance in the text zones.
4. All 20 prompts share the same **Style Anchor** (baked into each prompt) so they read as one film.
5. After selection, these become the **start frames** for Veo2 image-to-video generation.

### The Color Law (do not deviate between slides)
| Color | Meaning | Hex anchor |
|-------|---------|-----------|
| Amber/sodium-orange | Chaos, ungoverned | #F59E0B / #F97316 |
